# /mcp — Servidor MCP

Cloudflare Worker + paquete npm. **Cliente delgado del API público** — nunca habla directo a la base (ADR-013).

4 herramientas, no 20: `buscar_entidad`, `explicar_estructura`, `rastrear_dinero`, `consultar_fundamento_legal`. Cada una devuelve siempre la cita: fuente, fecha de captura, enlace al documento. Rate limit desde el día uno. Sin autenticación: son datos públicos.
